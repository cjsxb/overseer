  1. Attach one fileA program or script (.py, .sh, .js, .ps1, .exe and more), or a ZIP containing one. Up to 20 MB.
  2. Overseer investigatesIt reads the file's code and strings, forms hypotheses and gathers evidence. The file is never opened or run.
  3. Watch the screenThe tools it uses, the evidence it finds and its final verdict play out live.
  • Gmail often blocks executables, even inside a ZIP. Scripts are the most reliable.
  • Only the attachment is inspected. Your message text is not read. Images and documents are ignored.
  • One scan runs at a time. If nothing appears, wait a minute and try again.
  • Please don't send personal or confidential files.

How it works

1. Static evidenceGhidra, capa, YARA and format parsers extract code, strings and imports.
2. First verdictA large language model reviews the evidence and gives an initial assessment.
3. InvestigationIf unsure, it tests a malicious and a benign explanation, requesting decompilation and decoding.
4. Cited verdictMalicious, benign, suspicious or unknown, with every claim tied to evidence.
